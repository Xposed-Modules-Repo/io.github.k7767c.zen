## 功能

- 视频播放：广告清单全局门、画质列表解锁（含 1080p / 4K / HDR 档位）、播放会话控制
- 视频界面：手势（音量 / 亮度 / 快进）、清爽屏幕、音量键切集
- 首页与个人页：广告卡过滤、个人页角标与快捷入口、启动直达指定页
- PicACG：去广告、开屏跳过、悬浮入口按钮
- 设置面板：宿主设置页右上角入口图标，面板内开关即时生效

## 安装

1. 安装 APK
2. LSPosed 中启用本模块，勾选作用域内的应用
3. 重启作用域应用

模块 APK 更新后重启作用域应用即可，无需重启系统。
