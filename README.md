## 功能

**红果双包**
- 视频播放：广告清单全局门、画质列表解锁（含 1080p / 4K / HDR 档位）、播放会话控制
- 视频界面：手势（音量 / 亮度 / 快进）、清爽屏幕、音量键切集、全屏 / 选集条 / 清屏 / 悬浮按钮独立开关
- 首页与个人页：广告卡过滤、个人页角标与快捷入口、启动直达指定页、隐藏首页公告与底部游戏

**PicACG**
- 拦截广告与开屏、禁用广告点击、隐藏首页公告、隐藏底部游戏、拦截外部跳转、自动最快线路

**抖音**
- 净化与拦截：开屏广告跳过、升级检测屏蔽、打扰弹窗屏蔽、信息流广告组件裁剪
- 信息流过滤：直播卡片、AI 生成、图文、文章、音乐推广
- 分享与转发：解除转发限制、分享链接净化、视频无水印、图集无水印、下载限制解除
- 播放与手势：倍速、双击评论、禁用双击点赞、播完自动上滑、暂停恢复
- 界面精简：底栏 / 顶栏项、角标、播放页控件（头像 / 关注 / 点赞 / 收藏 / 评论 / 分享 / 音乐播放器 / 全屏）、三区控件透明度、按组件 Set 隐藏元素
- 面板精简：长按面板分组与条目、分享面板动作逐项隐藏
- 播放保护：视频失效时不自动跳过、定时关闭、后台播放
- 本地解锁：会员特权与付费内容的本地判定解锁、会员标识显示（本地装饰，不代表真实权益）

**小红书**
- 净化：开屏广告、信息流广告卡（数据层 12 个 getter 置空）、直播卡、打扰弹窗、升级弹窗
- 播放与手势：默认倍速、长按 2× 播放、禁用双击点赞
- 下载与分享：解除下载限制、视频无水印、图集无水印、分享链接净化
- 界面精简：首页顶部频道栏与底部 tab 项逐项隐藏

**六端通用**
- 软件 DPI：档位 `跟随宿主 / 305 / 365 / 425 / 485 / 545`，dpi 越大界面元素越大；改档立即生效
- 模块主界面：LSPosed 连接状态、六端版本比对与一键打开、反馈与赞赏入口
- 设置面板：宿主设置页右上角入口图标，面板内开关即时生效；音量加 / 减同时按下亦可唤出

## 安装

1. 安装 APK
2. LSPosed 中启用本模块，勾选作用域内的应用
3. 重启作用域应用

模块 APK 更新后重启作用域应用即可，无需重启系统。
