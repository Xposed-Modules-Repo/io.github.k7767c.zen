# zen

红果免费漫剧 / 红果免费短剧 / PicACG 三应用增强模块（libxposed API 102）。

## 作用域与适配版本

| 应用 | 包名 | 适配版本 |
|---|---|---|
| 红果免费漫剧 | `com.kylin.read` | 7.4.3.32 (74332) |
| 红果免费短剧 | `com.phoenix.read` | 7.3.1.32 (73132) |
| PicACG | `com.picacg.picacomic` | 2.6.71 (2026081114) |

## 功能

- 视频播放：广告清单全局门、画质列表解锁（含 1080p / 4K / HDR 档位）、播放会话控制
- 视频界面：手势（音量 / 亮度 / 快进）、清爽屏幕、音量键切集、全屏 / 选集条 / 清屏 / 悬浮按钮独立开关
- 首页与个人页：广告卡过滤、个人页角标与快捷入口、启动直达指定页、隐藏首页公告与底部游戏
- PicACG：拦截广告与开屏、禁用广告点击、隐藏首页公告、隐藏底部游戏、拦截外部跳转、自动最快线路
- 模块主界面：LSPosed 连接状态、三端版本比对、点击直接打开宿主、反馈与赞赏入口
- 设置面板：宿主设置页右上角入口图标，面板内开关即时生效；音量加/减同时按下亦可唤出

## 安装

1. 安装 APK
2. LSPosed 中启用本模块，勾选作用域内的应用
3. 重启作用域应用

模块 APK 更新后重启作用域应用即可，无需重启系统。
